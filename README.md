# Rhein UX Portfolio

Dark technology-style UX portfolio for Rhein Tao.

## Local Preview

Open `index.html` directly in a browser, or serve this folder as a static site.

## Deploy

This project is static and can be deployed to GitHub Pages, Vercel, Netlify, or any static host.

### GitHub Pages

Push this repository to `Rh3in/Rhein`, then open GitHub repository settings and set Pages to deploy from GitHub Actions.

Expected public URL:

```text
https://rh3in.github.io/Rhein/
```

### Continue In Codex On Another Computer

1. Install Codex Desktop and sign in on the other computer.
2. Clone the repository:

```bash
git clone https://github.com/Rh3in/Rhein.git
cd Rhein
```

3. Open the `Rhein` folder in Codex and ask it to continue editing the portfolio.
4. After each edit, commit and push:

```bash
git add .
git commit -m "Update portfolio"
git push
```

GitHub Pages will redeploy automatically after every push to `main`.
